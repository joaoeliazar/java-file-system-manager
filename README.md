# Java File System Manager

A command-line file management application built in Java that simulates common Unix-style file system operations.

The project was designed to practice object-oriented programming, file handling, path manipulation, recursive operations, and command-line application development in Java.

---

## Features

- Create files and directories
- List directory contents
- Rename files and directories
- Delete files
- Recursively delete directories
- Search for files using patterns
- Inspect file metadata
- Navigate through directories
- Handle invalid commands and file system errors
- Interactive command-line interface

---

## Technologies

- Java
- Java NIO / File API
- Object-Oriented Programming
- Command-Line Interface
